# 论文与技术报告调研标准

## 适用范围

对**论文、技术报告、官方博客**进行调研分析时，按本标准组织文档。

典型场景：
- 新模型复现前，调研原始论文和 tech report（如 Qwen3 技术报告）
- 训练方法/算法论文分析（如新的并行策略、优化器、数据配方）
- 竞品/前沿进展追踪

目的：
- 提取可指导工程实现的关键信息（不是写论文摘要）
- 识别复现关键点：什么必须精确对齐，什么可以忽略
- 为后续实现决策（选体系、选精度、选并行策略）提供依据

---

## 一、核心原则

| # | 原则 | 一句话要求 |
|---|------|-----------|
| 1 | **工程导向** | 所有信息服务于"能复现/能实现"，非工程相关内容可略过 |
| 2 | **数据优先** | 训练超参、数据规模、计算量等定量信息必须精确摘录 |
| 3 | **区分确定与推测** | 论文明确给出的标 [confirmed]，需要推测的标 [inferred] |
| 4 | **对比已有实现** | 如已有开源实现，标注论文描述与实现的差异 |
| 5 | **标注来源** | 每条关键信息标注章节号（如 §3.2, Table 4） |

### 2.6 关键创新点

## 三、质量检查清单

- [ ] 所有定量数据有来源标注（§/Table/Figure）
- [ ] 区分了 [confirmed] 和 [inferred] 信息
- [ ] 训练配置提取完整（optimizer、lr、batch、sequence length）

- [ ] 给出了可行动的实现决策建议
